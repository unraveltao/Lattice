[store.ts](../../src/platform/store.ts) 的 `hydrated` 闸门阻止异步水合结束前写盘，但**不保证水合成功**。
读取异常会被当成空值，解析失败也会放开闸门；下一次状态变更可能把默认值写回，见 [审查 F2](./review-2026-11-02.md#f2-失败水合后默认状态可以覆盖原文件)。
平台状态由 [state.rs](../../src-tauri/src/state.rs) 直接写临时文件再 rename，**没有**组件存储那套一代备份，也没有显式 `fsync` 耐久保证。
加新的持久化字段时，记得同时改 `partialize`，否则重启就丢。

`profile`（本机档案）不是账号系统：平台没有服务端，登录只是把昵称/邮箱写进同一份 `state.json`，用于界面上的称呼。**不要**把它当成身份或权限依据 —— 组件授权看的是 `grants`，与是否登录无关。真要做多设备同步时，换掉 `store.ts` 里的 `signIn` / `signOut` 即可，`SettingsMenu.tsx` 不用动。使用记录也不归档案：它在 `usage.json`，Sign out 不清它，只有档案页底部的 `Clear usage history` 清。
