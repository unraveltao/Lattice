# LAT-0043 —— 没有 Todoist 账号的人也得能用（`lattice.todoist` 0.2.0）

## 1. 问题

0042 是按"自己用"设计的：卡片第一次打开只有一行输入框，要求粘一个 token。组件一旦发给别人，这句话对**没有 Todoist 账号**的人就是终点 —— 他看到一块永久空白的卡片，而它是他自己从商店里拖到桌面上的。

两个坏结果：

- **卡片占着位置，但永远不会显示内容。** 桌面组件最贵的成本是屏幕面积。一块"要你先去别家注册"的空白，比不装更糟。
- **"用不了"的三种含义被合成了一句。** 没填过 token、token 在 Todoist 里被重置、`secrets.bin` 解不开（换了 Windows 账户）—— 0.1.0 里都是同一个 setup 界面。用户不知道是该去注册，还是该重新粘一遍。

用户原话："用户使用不了的话，也得有一个最基础的 To Do 的功能"。所以这一版要回答的不是"怎么把错误说清楚"，而是**没有账号的人打开这张卡，能干什么**。

## 2. 候选

| | A 只写清门槛 | B 卡内一个最小本地清单（选中） | C 指路到 `lattice.todo` |
| --- | --- | --- | --- |
| 做法 | 不改代码，help 里加一句"需要 Todoist 账号" | 没有 token 时卡片是一张能加能勾能删的清单 | 首屏一句"你该用内置的待办" + 一个按钮 |
| 换掉什么 | 无 | 空白首屏 | 把用户推去装第二个组件 |
| 新增什么 | 无 | `local` 存储键、第二套渲染、加/勾/删三个操作 | 一次跳转 |
| 代价 | 这批人的卡片**永久空白**，而且他分不清是"设计如此"还是"坏了" | 和 `lattice.todo` 功能重叠；两套数据来源 = 四个视图状态；本地那份**不能分档**（0038） | 用户装了两个待办组件，得先弄懂"我该用哪个" —— 而这两张卡长得一样 |

选 B 的理由不是"顺手做个待办"，而是**这张卡在用户桌面上必须有一个非空的状态**。C 最省事，但它把组件变成了广告牌：点完还是要去装另一个组件，中间那一步没有任何产出。

## 3. 决定

**B。本地那一档是草稿本，不是第二份待办。**

五条细则，每条都否掉了一个当时想选的：

1. **不存"模式"标记。** 本来想选：`storage` 里放 `mode: "local" | "remote"`。否掉的理由 —— 多一个字段就多一处"标记说有、数据却没有"的错法（标记是 `local` 而清单是空的 → 一张空卡片，比 setup 更难解释）。判据改成**推**：没有 token 且 `local` 非空 → 草稿本；否则 → setup。
2. **勾掉不删，只是划线。** 本来想选：勾掉即删（和 Todoist 的语义一致）。否掉 —— 这里是唯一副本，没有服务端回收站，误点一次就没了；而"再点一次回来"零成本。删除另有一颗 `×`，那才是明确动作。
3. **接上 Todoist 时说一次"N 条留在本机"，之后不再提。** 本来想选：顶部常驻一行提示。否掉 —— 接上之后用户要的是远端列表，常驻一行等于每天提醒他"你还有一份看不到的清单"。一次性提示 12 秒（`NOTE_MS`）后自己消失，可手动关，**不重复弹**。
4. **改名 `Tasks for Todoist` / `Todoist 待办` + 免责声明。** 原名 `Todoist` 违反 Todoist 品牌规则（"Todoist" 不能作为应用主名）。**id 仍是 `lattice.todoist`** —— 改 id 等于换一个组件，已装用户的存储和密封 token 一起失联，而这里要改的只是显示名。
5. **加 `shell:open`，只发一个固定 URL。** 0042 §4 明写"不申请 `shell:open` —— 为了 help 里一个链接多一项权限不值"。推翻它的原因变了：现在有一颗**按钮**要打开 Todoist 的 token 设置页（`app.todoist.com/app/settings/integrations/developer`），用户不用照着文字自己找。代价是已装用户会看到一次新权限复核 —— 这个组件还没发版，代价是零。

**代价**，具体的：

- 视图状态 2 个 → 4 个（`setup` / `local` / `remote` / `remote-error`），渲染函数 1 套 → 2 套（`renderRemoteList` 与 `renderLocalList` 几乎对称）。`widget.js` 750 行，草稿本直接占约 150 行。将来给列表加排序或搜索，要写两遍。
- 本地清单和 `lattice.todo` 功能重叠。两个都装的人会发现本地那份**没有档位** —— 故意的：有了档位它就成了竞品，而它的定位是"没账号时的兜底"。help 里直说"想要一个正经的本地待办，装「待办」那个组件"。
- 显示名和 id 不一致：搜"Todoist"还能找到它，但目录标题第一眼不是品牌名。

**什么时候该推翻它**：

- **Todoist OAuth 打通。** PKCE 对公开客户端可行，但 `redirect_uris` 要求 HTTPS（localhost 只给测试），组件沙箱里没有可用的回环地址 —— 这是平台级的事，记在 `ROADMAP` 里不排期。打通之后"没 token"变成"点一下登录"，草稿本不该再是默认首屏。
- **出现第二个要 token 的组件** → 该做 `config type: "secret"`（0042 §3c），token 输入框搬进属性面板，setup 缩成一句"去属性面板填"。

## 4. 接口与数据

清单：`permissions: ["network", "secret", "storage", "shell:open"]`，`network.hosts: ["api.todoist.com"]` 不变。桥**一个方法都没加**。

`shell.open` 只接受本文件里那一个常量（`TOKEN_PAGE`），用户输入不经过它 —— 组件没有"能打开任意网址"的口子。

落盘（`widget-data/lattice.todoist.json`）从一份变两份，同一个文件两个键：

```
{ "cache": { "v": 1, "at": <ms>, "tasks": [ … ] },
  "local": [ { "id": "m3k9x1ab", "text": "…", "done": false } ] }
```

- `local` ≤ 100 条（`MAX_LOCAL`）、`text` ≤ 160 字（和缓存同一个 `MAX_TEXT`）。新的落在最上面。
- **`local` 没有 `v`。** 缓存有版本是因为它是加速、整份作废不要钱；草稿是**唯一副本**，所以 `normalizeLocalItems` 逐条过、坏一条丢一条。整份作废在这里等于"换个版本就清空用户记的事"。
- `done` 只认 `true`；脏值（`"1"`、`1`、`"true"`）一律当没做完 —— 不猜。
- **token 仍然一个字节都不在这份文件里。**

视图不落盘：`data-view` 由启动时三份读取（`cache` / `local` / `token`）推出来，`Promise.all` 之后才发 `ready` —— 早发的话宿主拿到的是一个还没决定"显示哪一档"的中间态。

## 5. 失败模式

| 症状 | 原因 | 正确行为 |
| --- | --- | --- |
| 装完打开，一张空卡片只有一行输入框，不知道该填什么 | 没有账号（用户澄清"用不了" = 不想注册） | 第二行就是"没有 Todoist？先用本地清单"，点了进草稿本，光标落在输入框 |
| 刚填完 token，本机记的 8 条不见了 | 视图切到 `remote`，草稿本不再渲染 | 12 秒的一次性提示说"N 条留在本机、不会同步；断开 Todoist 就能看到它们" |
| 提示一闪就没了，没看清 | 用户正好在看别处 | 12 秒 + 手动关；**不重复弹** —— 它说的是"已经发生的事"，不是"待处理的事" |
| 把本地那几行当成 Todoist 里的 | 两种行长得一样 | 本地行没有优先级圆点、没有日期；底栏常驻"本地 · 不会同步" |
| 点"打开设置页"没反应 | 不在桌面里 / 没有默认浏览器 | 静默 —— 上面那行字已写清完整路径，这条只是少找两步 |
| 勾掉的那行还在，以为没勾上 | 勾掉是划线不是删 | 划线 + 灰掉，再点一次回来；删除另有一颗 `×` |
| 两个实例，一个加了一条，另一个不动 | 没有跨实例通知 | `store-changed`（`key` 为空或 `local`）→ 重读；自己写的回声靠 `touched` + JSON 比较挡掉 |
| 在草稿本里点了底栏那颗云，又不想连了 —— **回不去** | setup 里那颗"用本地清单"按"本地有条目就别再劝"藏掉了，而它是这条路上唯一的回路 | 没有 token 时它一直在，标签跟着变「返回本地清单」。**这条是补断言时抓到的**：卡片会停在 setup，那几条再也看不见，只能关掉重开 |
| 本地满 100 条，按回车没反应 | 静默拒绝 | 底栏写"本地清单满了（100 条）" |
| 断开 Todoist 之后卡片变空白 | 视图没决定去哪 | 本地有东西 → 草稿本；空的 → setup。**两边都不删数据** |

## 6. 验收

`tests/todoist.html` **158 条**（纯逻辑 63 + 挂真组件 95）。0.2.0 新增 55 条：

| 组 | 钉住什么 |
| --- | --- |
| 11 | 草稿本能加、能勾、勾掉**留在列表里**、能删，三个动作都落盘；勾选框和 `×` 的标签带条目内容（不是一排"完成"） |
| 12 | `local` 非空 + 没有 token → 首屏直接是草稿本（不是 setup） |
| 13 | 接上 Todoist 的提示带条数、说"不会同步"、可关，之后列表是远端的；从草稿本点进 setup 之后**回得去** |
| 14 | 断开 → 本地有东西回草稿本、空的回 setup |
| 15 | "打开设置页"发的是那一个固定 URL |
| 16 | 断开时那条提示一起收起来（它讲的是"你现在看不见它们"） |

最要紧的两条仍是 0042 留下的：**token 一次都没出现在 `storage.set` 里**、失败时**列表不清空**。

**手工验一次**：先断开 Todoist，加三条 → 关掉组件 → 重开还在；填一个真 token，确认提示写的是 3 条、远端列表出来；再断开，三条还在。
