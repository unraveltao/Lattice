# 常见问题

按"你现在卡在哪一步"分四组。每条都是**症状 → 原因 → 怎么办**，没有铺垫。

找不到答案，去 [Issues](https://github.com/unraveltao/Lattice/issues) 搜一句症状，多半有人问过；
还是没有就开一条，**带上第四节说的三样东西**。

---

## 一、装之前

### 它支持什么系统？

Windows 10 / 11，64 位。没有 macOS 和 Linux 版本，也没有这个计划 —— 整个窗口层是 Win32 的
（`SetWindowRgn`、WorkerW、`DwmEnableBlurBehindWindow`），换平台等于重写。

### 需要先装什么吗？

一般不用。组件跑在系统的 WebView2 里，Windows 11 自带，Windows 10 装了新版 Edge 的也都有。
真没有的话，安装包会自己下载一份。

### 装的时候弹「Windows 已保护你的电脑」

**安装包还没有做代码签名**（一张 OV 证书一年几百美元，这条路正在走开源项目的免费方案，
进度写在 [`CODE_SIGNING.md`](./CODE_SIGNING.md)）。

点 **更多信息 → 仍要运行** 就装上了。介意的话可以核验：发布页的说明里有安装包的 SHA-256，
下载完在 PowerShell 里跑 `Get-FileHash .\Lattice_0.1.2_x64-setup.exe -Algorithm SHA256`，
两串对得上再装。

这不是"没做"，是"还没买"。真有问题的是**装完第一次运行**被拦之后你没点继续 —— 那才是真装不上。

## 二、第一次运行

### 装完了，里面是空的，一个组件都没有

**这是对的。** 平台自己不带任何组件 —— 官方的 20 个和第三方的走同一条安装链路，
你装了什么才有什么。

三个入口，都试一下就知道哪个顺手：

- **组件库最上面那段「可安装」** —— 点一下直接装，不弹窗。
- **组件库下面的商店段（目录）** —— 每条要先摊开看一眼版本、签名、要哪些权限，
  再点 Install。第三方组件只从这里进。
- **把组件文件夹或 `.lattice` 包拖进窗口** —— 拖到哪儿都行，会问你确认。

### 组件装到哪儿了？

```
%APPDATA%\com.iron-tom.lattice\widgets\<组件 id>\
```

在文件管理器地址栏粘 `%APPDATA%\com.iron-tom.lattice` 就能进去。

### 我的布局、待办、背的单词存在哪儿？

同一个目录下：`state.json`（布局与授权）、`widget-data\`（每个组件自己的数据）。
备份就是把整个 `com.iron-tom.lattice` 文件夹复制走。

### 怎么让组件出现在桌面上？

装完之后它先进**组件库**，点一下才落到**画布**上 —— 画布是编辑区，还不是桌面。
把它变成桌面上那个真窗口的是顶栏右边那颗 **「投放到桌面」**（`Send to desktop`）：
点下去画布上的所有组件都变成贴壁纸的窗口，主窗口自己退到一边。要回来点同一颗，
这时它写「收回来」。

落到桌面上之后还剩一件事：**它盖在谁上面**。属性面板 → `Layer & size` → `Layer`：

- **桌面**：在图标之上、普通窗口之下 —— 切去别的程序永远盖不住它，但也不会挡住你干活。
- **置顶**：浮在所有窗口上面，适合监控、读数这类要一直看得见的。

## 三、用的时候

### 组件突然不见了

两种可能，都留了后路：

- **手滑删了**：窗口底部正中会弹一条「已移除 ⋯ 撤销」，**只活 8 秒**，点「撤销」就回来。
- **当时没看见**：组件库最底下的「最近删除」，留 20 条 / 7 天。过了这个窗口就真没了。

### 组件不刷新了，像卡住

大概率是**它被挡住了**。平台会在组件看不见的时候停掉它的刷新（最小化、收起、
被别的窗口整个盖住都算），这是省电的设计，不是坏了 —— 把它露出来，一秒内自己就恢复。

只有一种情况要担心：组件自己崩了。那时候主窗口底部会出现一条提示，点重试。

### 点组件没反应，像隔着一层玻璃

属性面板里的 **鼠标穿透（Click-through）** 打开了。关掉它。

### 拖不动组件

**锁上了。** 鼠标移到组件上，右上角会浮出一排小按钮，那颗别针（`锁定位置`）按下去就锁住
位置和大小，再按一次解开。锁是防手滑的：锁着的时候连拖都不响应，四个边上的缩放手柄
也一起收掉。

### 两个显示器上位置乱跑

位置是**按屏幕记的**，混着不同缩放也不会跑偏 —— 但前提是两块屏都在。
拔掉一块再插回来，另一块屏上的组件会被夹回当前屏幕的可见范围，这是有意的（总比丢到屏幕外强）。

### 界面是英文 / 组件里的字是英文

设置 → 语言 里三档：跟随系统 / 中文 / English。**组件里的字也会跟着换**
（星期、`还剩 2 项`、按钮），不用重启，已经开着的窗口当场变。

如果切了之后个别组件还是旧语言，把它删了重新拖一次 —— 那是老版本的组件，清单里只有英文。

### 底板调不出"透出后面的窗口"的效果

磨砂用的是系统的模糊半径，那个值是写死的：要么有模糊但只能透出壁纸，要么能透出窗口但完全没有模糊。
**两个不能同时要**，这是 Windows 的限制，不是没做。

## 四、更新、卸载、报问题

### 检查更新失败

平台只从 GitHub Releases 取更新。国内网络下 `github.com` 和 `objects.githubusercontent.com`
都可能连不上 —— 那种时候去 [Releases](https://github.com/unraveltao/Lattice/releases/latest)
手动下新的安装包，直接覆盖安装即可，布局和组件都在。

### 卸载会删掉我的组件和数据吗？

**不会。** 卸载只删程序本身和开机自启那一项。`%APPDATA%\com.iron-tom.lattice` 原样留着 ——
重装之后布局、组件、待办全都还在。真不要了，手动删那个文件夹。

### 想报一个问题，该带什么？

三样，缺一样都很难查：

1. **版本号**：设置 → 关于 里那个 `0.1.x`
2. **复现步骤**：点到哪儿、做了什么、期望看到什么、实际看到什么
3. **日志**：平台自己不写运行日志（只在你用过助手时留一份
   `%APPDATA%\com.iron-tom.lattice\agent\audit.log`，记的是"它替你改了什么"）。
   组件的问题靠**调试面板**：`Ctrl+Shift+D` 打开，它实时显示桥调用和组件里的
   `console` 输出，把报错那几行截下来就够了。

### 我能自己写一个组件吗？

能，这就是这个项目的重点。三样东西，按顺序看：

- **`README` 的 *Write a widget* 一节**（[英文](../README.md#write-a-widget) /
  [中文](../README.zh-CN.md#写一个组件)）—— 四个文件、一段示例、三条会被平台惩罚的习惯。
- **[`examples/counter`](../examples/counter)** —— 能跑的最小实现，照抄结构最快。
- **[`WIDGET_SPEC.md`](./WIDGET_SPEC.md)** —— 契约：方法表、配置字段、清单规则，
  以及"组件真跑起来之后才会撞到"的坑。

一条命令起个头（`--out` 指到仓库外，别往官方组件目录里塞自己的东西）：

```bash
git clone https://github.com/unraveltao/Lattice
cd Lattice && npm install
npm run create:widget -- demo.mine --out ../my-widgets/demo.mine
```

生成出来的文件夹**拖进应用窗口**就装上了；改完代码点组件右上角的刷新按钮，不用重装。
